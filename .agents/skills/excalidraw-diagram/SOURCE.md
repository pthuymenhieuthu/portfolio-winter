# Source

Installed for the user-approved MedHunt story sketches from:
https://github.com/coleam00/excalidraw-diagram-skill

The MedHunt palette uses the portfolio's existing colors. The renderer is adapted to use a locally bundled Excalidraw module and system Chromium instead of the unavailable esm.sh service. Runtime drawing dependencies stay outside the portfolio app; only exported static SVG assets are loaded by the site.
