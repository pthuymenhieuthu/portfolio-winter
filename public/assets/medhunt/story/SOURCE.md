# MedHunt team-story sketches

Four editable Excalidraw scenes and their static SVG/PNG exports. The portfolio loads the SVG files only; the drawing library is not added to the app bundle.

The scene order follows the user-approved content: shared-code edits overlapping with evolving logic, agreeing on business rules with the BA, expressing behavior in a standalone HTML prototype, and sharing that prototype with the frontend developer.

The interview/offer example uses labels and actions from `public/assets/medhunt/prototype/CaseDetail.dc.html`: an interview result can lead to the passed-interview stage and the create-offer action. Candidate C-101 is demonstration data from the existing prototype. Code-window lines are schematic, not a claim about shipped frontend code.

Generated and visually checked with `.agents/skills/excalidraw-diagram`. Open the `.excalidraw` files in Excalidraw to edit them, then use the skill's renderer to update SVG and PNG. The artwork uses the existing portfolio palette with thin hand-drawn strokes and concrete people, documents and UI windows.
