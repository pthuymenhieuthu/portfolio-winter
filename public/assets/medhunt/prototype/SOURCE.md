# Source

Prototype: healthcare-talent/prototype-medhunt-blue. The supplied standalone HTML, scripts, styles, runtime and assets are copied locally for the MedHunt case study. Main.dc.html's initial gate and page open the demo dashboard directly, and its embedded-only CSS hides the internal style-comparison controls. The original healthcare-talent repository is unchanged.

Computer frame: silver iMac from Devices.css by Yan Zhu (MIT), adapted into the page-scoped medhunt-prototype.module.css. Source: https://github.com/picturepan2/devices.css/blob/1184624/src/_imac.scss

The frame is static. No WebGL renderer or animation dependency is added. Keep DEVICES-CSS-LICENSE.txt when redistributing the adapted frame.
